# Engine-for-3d-games
This is an openGl/C++ project.This project loads 3d models using the ASSET IMPORT LOADER (ASSIMP) and Loads Textures using the STB_IMAGE lIBRARY. This started as me trying to learn how to render 3d-objects and make them do fancy stuff using C/C++ but it has evolved into something i'd refer to as a mini-engine. In this repository you will find some files i am not direclty using but were old files i wrote which i used to reference most of what i wanted to build.In this project i am using my own custom Physics i did not use BULLET OR JOLT PHYSICS Libraries not beacuse i did not want to use them problems is, it was hard intergrating them in my code ,the linker errors were enormous so everything is basically custom in this project so the maybe basic compared to your unity and  unreal. This is a project i will not do again after i am done i just wanted to see if i can build an engine. This is still in development. please check the latest files for the engine progress.
