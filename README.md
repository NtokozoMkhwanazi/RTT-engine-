# 3D GAME Engine 
This is a game engine project i made in C++ using openGl API  
# what it can do  
- Reliable Camera SmoothFollowPlayer
- character controllers still basic because animation system is still in development
- Load Models of different types .fbx, .gltf etc
- Render Skyboxes with blending .
- Load Skeletons and Bones.
- Custom Phyics tailored for this engine.
# what it fails to do for now 
- Animation system is still being developed. So this means animation is not properly working but its there.
