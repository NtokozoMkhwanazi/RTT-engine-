# 3D GAME Engine 
This is a game engine project i am currently developing just for learning more about the technicalities of graphics programming and 3D Game Development. Probaby the most difficult project i have tackled so far,  feel free to get your hands dirty code is in the repository just put the The header files in same folder and their .cpp file then compile main outside the folder make sure you have all the required libraries i.e STBI-LIBRARY ASSIMP Library, OpenGl Library,And C/C++17 or latest.     
# what it can do  
- Reliable Camera SmoothFollowPlayer
- character controllers still basic because animation system is still in development
- Load Models of different types .fbx, .gltf etc
- Render Skyboxes with blending .
- Load Skeletons and Bones.
- Custom Phyics tailored for this engine.
# what it fails to do for now 
- Animation system is still being developed. So this means animation is not properly working but its there.
