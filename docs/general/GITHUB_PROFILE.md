## 🚀 Featured Projects

### ⚙️ RTT-Engine (Full-Featured 3D Game Engine)
*A modular, general-purpose game engine built from scratch for games, simulations & interactive experiences*
- **Tech:** C++17, OpenGL 3.3+, GLSL, ASSIMP, GLFW, GLM
- **Core Systems:**
  - 🎨 Rendering (GPU skinning, batch rendering, instancing, PBR-ready)
  - 🌍 World Streaming (procedural terrain, chunk LOD, vegetation, water)
  - 🦴 Animation (skeletal, blending, root motion, foot IK, state machines)
  - 🧠 Physics (collision, rigid bodies, constraints, CCD, raycasting)
  - 🎮 Character Controller (third-person, camera modes, movement)
  - 🔊 Audio (OpenAL 3D spatial)
  - 🧱 ECS Architecture (component-based, memory pooling)
- **Philosophy:** Modularity, Low-Level Control, Performance First, Educational
- **Status:** Alpha — Core systems functional, expanding features
